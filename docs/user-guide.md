# Work orders and asset release

Operations coordinators create draft work orders, assign technicians, and publish or schedule the work. A draft is not an active repair. An assigned technician can start open or scheduled work, record checklist progress, notes, labor and private image evidence, declare the people who performed the repair, and submit the current revision for review.

Blocking work requires a reason. Technicians can block an in-progress repair, but only an operations coordinator can resume blocked work, either directly to in progress or back to scheduled. An assigned technician can then start the scheduled job. A resume reason is required and recorded in the work history.

An operations coordinator who did not participate in the repair reviews its submitted revision. The coordinator can approve it or return it for correction. A returned repair can be updated and submitted as a new material revision; performers must be declared again for that revision. People recorded as performers or repair participants remain ineligible to review that work order even after assignment or role changes.

Repair approval records that the work passed review. It does not release the asset. In Assets, resolve each active safety hold with its actual resolution, confirm the current condition and recorded checks, then record the separate release acknowledgment. The service rechecks release eligibility when the action is submitted.
